name: ONLYONE engineering workflow
description: Project roles, approval gates, and the limits of the supplied engineering-standard summary.
---

The project follows this role split: the owner decides and authorizes, the
architect defines and independently audits, and the executor implements only
the work authorized by the owner.

The required stages are definition, analysis, specification, authorized
implementation, self-verification with evidence, independent audit, and owner
approval.

Only this summary has been provided; do not invent the contents of the full
standard. If the full document is necessary for a task, wait until it is
available.

**Why:** The project owner supplied these constraints for the ONLYONE MUSIC
STUDIO project.

**How to apply:** Keep work within the explicitly authorized phase, provide
verifiable implementation evidence, and do not describe implementation as
approved before the owner's approval.
